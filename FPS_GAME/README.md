# FPS GAME - Tactical FPS Web Game

2D/3D Tactical FPS Web Game built with HTML5 Canvas, JavaScript, Node.js, and Socket.IO.

## Features
- **Tactical Multiplayer**: Real-time multiplayer synchronization using Socket.IO.
- **Character & Weapons**: Agent data, ability systems, weapon systems, wallbang dynamics.
- **Game Systems**: Round management, economy system, shop system, audio, HUD, damage text, and minimap.

## How to Run

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Server
```bash
npm start
```
or for development mode:
```bash
npm run dev
```

### 3. Open Game
Open your browser and navigate to `http://localhost:3000`.
